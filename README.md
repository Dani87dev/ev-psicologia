# ev-psicologia

Custom-built website for a psychology practice, developed by Estudi Vilà.

## Overview

A bespoke static website designed and developed to measure for a professional psychologist. It presents her approach, services, training and contact options, with a clean, accessible and responsive design.

The project was built with the assistance of [Claude Code](https://www.anthropic.com/claude-code) as part of the development workflow.

## Tech stack

- HTML5
- CSS3
- JavaScript (vanilla)
- Hosted on GitHub Pages with a custom domain

## Features

- Responsive layout for mobile, tablet and desktop
- Sections: Home, About, Approach, Sessions, Training, Contact
- Contact via WhatsApp and email
- Spanish version (Catalan planned)
